# 第一版功能范围（MVP）

## 1. 必须实现

### 文件入口

- 打开单个图片或视频
- 打开文件夹
- 拖入文件或文件夹
- 自动读取当前媒体所在目录中的其他受支持媒体

### 瀑布流

- 图片、动图和视频混合显示
- 保持原始宽高比例
- 窗口宽度变化时自适应列数
- 调节缩略图尺寸
- 异步加载缩略图
- 可见区域优先
- 视频显示封面、类型和时长
- 返回时保持选中项和滚动位置

### 图片查看

- 适应窗口
- 原始尺寸
- 放大和缩小
- 以鼠标位置为缩放中心
- 鼠标拖动
- 上一个和下一个媒体
- 全屏

### 视频查看

- 播放和暂停
- 进度控制
- 音量和静音
- 视频时长
- 全屏
- 上一个和下一个媒体

### 组织和文件操作

- 按名称、修改时间和文件大小排序
- 正序和倒序
- 全部、图片、动图、视频筛选
- 文件名搜索
- 重命名
- 删除到回收站
- 在资源管理器中显示
- 复制文件路径

### 设置

- 深色、浅色、跟随系统
- 默认缩略图尺寸
- 默认排序方式
- 默认视频音量和静音状态
- 缩略图缓存容量
- 清理缓存

## 2. 首批格式

### 图片

- JPEG/JPG
- PNG
- BMP
- GIF
- WebP
- TIFF
- ICO

### 视频

- MP4
- MKV
- WebM
- MOV
- AVI
- WMV
- M4V

视频兼容范围以随应用提供的 VLC 组件为准。

## 3. 第一版暂不实现

- 图片编辑、裁剪和滤镜
- 云同步和用户账号
- AI 分类和人脸识别
- 重复图片检测
- 标签和评分数据库
- 在线媒体源
- 完整 RAW 支持
- PSD 编辑
- 悬停自动播放所有视频
- 插件系统

## 4. 验收标准

- 文件夹扫描不冻结界面。
- 可以浏览至少 10,000 个轻量媒体条目而不一次性加载全部原图。
- 点击瀑布流项目可进入查看器并正确返回原位置。
- 大图缩放和拖动操作连续、方向正确。
- 常见视频可播放，关闭或切换后文件句柄得到释放。
- 缩略图第二次打开时可从缓存复用。
- 损坏文件显示错误占位但不会导致应用崩溃。
- 支持中文、空格和常见特殊字符路径。
- 在 Windows 高 DPI 设置下界面尺寸和点击区域正常。
