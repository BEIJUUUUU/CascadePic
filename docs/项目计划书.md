# Windows 瀑布流图片与视频查看器项目计划书

## 1. 产品定位

开发一款面向 Windows 10/11 的本地图片与视频查看器。软件强调简洁、快速和低干扰，并提供传统图片查看器较少具备的文件夹瀑布流浏览模式。

核心价值：

- 快速打开本地图片和视频
- 将同一文件夹中的图片、动图和视频混合呈现在瀑布流中
- 点击项目进入沉浸式查看，返回后保留浏览位置
- 不要求账号，不依赖网络，不上传媒体内容

## 2. 主要使用场景

### 2.1 单文件查看

用户双击或拖入图片/视频后打开媒体，并自动发现同目录中的其他受支持文件。可通过方向键切换前后文件。

### 2.2 文件夹瀑布流

用户选择或拖入文件夹后，程序异步扫描媒体文件、生成缩略图并按原始宽高比排列。点击项目进入查看器，退出后回到原滚动位置。

### 2.3 视频浏览

瀑布流中的视频显示封面、类型标识和时长。进入查看器后提供播放、暂停、进度、音量和全屏控制。

## 3. 产品原则

- 内容优先：界面元素不遮挡媒体内容。
- 快速反馈：扫描和缩略图生成不能冻结窗口。
- 渐进加载：先显示文件列表和占位，再逐步补充缩略图。
- 资源有界：线程、内存缓存和预加载数量都有明确上限。
- 本地优先：默认不联网，不收集用户媒体信息。
- 容错优先：单个文件损坏不影响整个文件夹浏览。

## 4. 阶段规划

### 阶段 A：项目初始化

- 建立 Git 与 GitHub 仓库
- 固化产品范围和技术方案
- 准备 Python 3.12 开发环境
- 建立基础目录、质量工具和测试框架

### 阶段 B：图片查看技术原型

- 打开常见图片
- 适应窗口和原始尺寸
- 以鼠标位置为中心缩放
- 拖动大图
- 测试超大图片和资源释放

### 阶段 C：瀑布流技术原型

- 异步扫描文件夹
- 读取媒体基本信息
- 瀑布流布局计算
- 可见区域渲染/虚拟化
- 异步缩略图加载
- 测试 100、1,000 和 10,000 个文件

### 阶段 D：缓存与视频

- 磁盘缩略图缓存
- 有上限的内存 LRU 缓存
- 视频封面和时长提取
- VLC 播放器集成
- 缓存失效和清理策略

### 阶段 E：完整 MVP

- 排序、筛选和搜索
- 文件拖放
- 前后切换
- 返回位置保持
- 文件重命名、回收站删除和资源管理器定位
- 设置页面、主题和快捷键

### 阶段 F：测试与发布

- Windows 10/11 测试
- 高 DPI 和多显示器测试
- 中文、特殊字符和长路径测试
- 损坏文件和外接磁盘测试
- PyInstaller 目录便携版
- 安装包方案评估

## 5. 质量目标

- 文件夹扫描期间界面保持可操作。
- 首屏媒体优先加载，不等待全目录完成。
- 大文件夹不会一次性解码全部原图。
- 单个损坏文件不会导致程序崩溃。
- 离开大图查看后能及时释放高占用资源。
- 返回瀑布流时保留之前的选中项和滚动位置。

## 6. 后续增强方向

MVP 稳定后再评估：HEIC/AVIF/RAW、EXIF 详情、幻灯片、双图对比、标签评分、重复图片查找、悬停视频预览和自动更新。
